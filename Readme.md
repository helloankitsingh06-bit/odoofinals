# Hackathon Starter Template

A domain-agnostic full-stack starter: **React + Vite** frontend, **Node/Express**
backend, **Firebase** (Auth + Firestore) for identity and data.

All business logic from the original project has been stripped out. What remains
is infrastructure plus one generic CRUD example (`items`) to copy and rename once
the problem statement is known.

> ⚠️ This template ships with **no Firebase project and no credentials**. Each
> team must create their own Firebase project and plug it in before running —
> see [`TEMPLATE_README.md` §3](./TEMPLATE_README.md#3-bring-your-own-firebase-project).

👉 **See [`TEMPLATE_README.md`](./TEMPLATE_README.md)** for full setup, run
instructions, and how to adapt the template.
